# Usage
To check, please, preview source files in `task1` folder.

Для запуска и проверки приложения перейдите в каталог `task1` и выполните команду:
`docker compose up --build`

Согласно требованиям, инфраструктура состоит из двух сервисов[cite: 7]. Программа 1 берет случайный файл с числами из примонтированного каталога `data` и передает его Программе 2 через связанный том промежуточных результатов (bind mount)[cite: 6, 8]. Программа 2 ищет в этом файле наибольшее число, выводит на экран и сохраняет количество таких чисел в папку `result`[cite: 8].
