# Usage
To check, please, preview source files in folders `task1` and `task2-2`.

**Задание 1 (Каталог task1):**
Для проверки работы распределенного приложения перейдите в каталог `task1` и выполните команду:
`docker compose up --build`
Входные данные берутся из `task1/data/`, промежуточные результаты сохраняются в `task1/result-1/`, а финальный результат — в `task1/result/`.

**Задание 2 (Каталог task2-2):**
Для проверки работы брокера RabbitMQ перейдите в каталог `task2-2` и запустите контейнер:
`docker compose up -d`
Интерфейс администрирования будет доступен по адресу `http://localhost:15672`. 
Код для уроков 1-3 написан на Python (библиотека pika) и хранится локально на хост-системе. Скрипты запускаются вручную из терминала, например: 
`python 1_receive.py` и `python 1_send.py`.
